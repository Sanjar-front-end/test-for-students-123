# Биология пәнінен емтихан порталы (Biology Exam Portal)

Өсімдіктер мен жануарлардағы гаметогенез және спорогенез тақырыбы бойынша биология пәніне арналған онлайн тестілеу платформасы.

## 🚀 Ерекшеліктері
- **Құрылғыны бекіту (Device-Lock):** Оқушы аты мен тегін енгізген соң, сол құрылғы 1 ай мерзімге сол оқушы үшін бекітіледі.
- **25 сұрақ (Дербес реттілік):** Әр оқушыға сұрақтар кездейсоқ ретпен беріледі.
- **Желілік қорғаныс (Anti-Cheat):** Сұрақтардың дұрыс жауаптары желілік трафикке (Network payload) жіберілмейді, жауаптар серверде тексеріледі.
- **10 минуттық нақты таймер:** Бетті қайта жүктегенде немесе жауып ашқанда да уақыт жалғасады. Уақыт біткен соң жауаптар автоматты түрде қабылданады.
- **Нәтижелер беті және шолу:** Қорытынды балл, пайыздық көрсеткіш және жұмсалған уақыт. Оқушы тек өзі таңдаған жауаптарын шолып қарай алады.
- **Әкімшілік панелі (ADMIN / PASSWORD):** Барлық тапсырған оқушылардың кестесі, статистика, іздеу/сүзгі және CSV форматында экспорттау.
- **Dark Mode UI:** Қазіргі заманғы қараңғы стиль, толықтай бейімделген (responsive) интерфейс.

## 🛠 Технологиялық стек
- **Next.js 16 (App Router)**
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Lucide React & Canvas Confetti**

## 💻 Іске қосу
```bash
npm install
npm run build
npm run start
```
Браузерде `http://localhost:3000` адресін ашыңыз.
